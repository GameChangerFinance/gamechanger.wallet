# Contributing

Thanks for helping improve GameChanger Wallet docs and examples. Small, focused pull requests are easiest to review. Use one PR per example or topic.

## Commit style

Use [Conventional Commits](https://www.conventionalcommits.org/) scoped to the area you touch, for example:

- `docs(examples): modernize Stake Withdrawal`
- `fix(examples): export the real lock from Helios Timelock`
- `docs(gcscript): clarify ISL scopes`

## Example style (`examples/*.gcscript`)

Examples are read by people, rendered as forms by codegen dapps and packed into URLs and QR codes. Write them for all three.

1. **Metadata.** Give the root script a `title` and a short `description` that says what the script does, what it needs first (for example "run 'Multi Stake Delegation' first") and what it returns. Add `exportAs` and `return` (usually `{"mode": "last"}`) when the example hands a result back to the dapp. A few minimal examples (`Simple Script No Export`, `Simple Script No Export No Return URL`) deliberately omit these to show they are optional. Keep them that way.
2. **Arguments.** Move user-tunable values (amounts, pool ids, addresses, indexes, asset names) into root `args` with flat kebab-case names (`withdrawal-quantity`, `pool-a`, `account-index`). Use string values for lovelace and token quantities, and JSON numbers for small integers. Codegen dapps render one form field per argument, so the default value should be a working example.
3. **Guards.** Check arguments with `assert()` before the wallet builds anything. Cover type, non-empty, bounds and format where relevant. Prefer a single `assert(and(...), 'short message')` unless a later check depends on an earlier one. Don't repeat a check the wallet already enforces.
4. **Requirements.** Review `require` (wallet types, network). Exclude wallet types that cannot run the script, such as `extension` for key derivation or `burner` / `gift` for staking.
5. **Size.** Keep the packed URL QR-encodable, with a margin. The QR ceiling at the default error correction (Q) is 1,663 bytes for the whole wallet URL. Measure with `gamechanger-cli <network> encode url -v 2 -f <file>`. Shrink by flattening wrapper scripts, shortening internal step names, merging asserts and trimming wording, never by dropping behaviour or safety checks.
6. **Behaviour.** A refactor must not change what the script derives, builds, signs or exports. If you fix a bug along the way, say so in the commit message.

## What to commit

Commit only the `.gcscript` source. Generated files (`.html`, `_nolib.html`, `_react.html`, `.md`, `.png`) are regenerated by the maintainers after review, so leave them out of your PR.

## Before opening a PR

- The file parses as strict JSON, and every `get('args.…')` and `get('cache.…')` path resolves.
- You generated the URL, QR and HTML dapp locally, opened them, and checked that the rendered form fields make sense to a developer and an end user.
- You ran the script on the wallet types and networks it targets (for example mainnet and preprod), including a failing-assert case.
- The PR description lists what you tested and on which wallets.
