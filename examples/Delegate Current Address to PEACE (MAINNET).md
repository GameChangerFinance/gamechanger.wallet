
# Cardano Example Dapp

## **Delegate Current Address to PEACE (MAINNET)**

About to delegate your ADA to 'PEACEpool Cardano ecosystem developers' stake pool. The stake key is registered and delegated in a single transaction, and an already registered stake key is handled, so the same script also works when re-delegating.
