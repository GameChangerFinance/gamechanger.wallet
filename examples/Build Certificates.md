
# Cardano Example Dapp

## **Build Certificates**

Builds stake registration, deregistration and delegation certificates for the three kinds of stake credential: a key derived from the current wallet, a native script and a Plutus script. Nothing is submitted: the certificates are exported so they can be inspected or reused in a transaction. The target pool of each delegation is exposed as a flat argument, and checked with assert() before anything is built
