
# Cardano Example Dapp

## **Simple Export**

Exports the wallet name, the current address, the spending and staking public keys and three data constants under a single export named 'wallet'. Shows how exportAs returns the results of a script to the dapp

  "exportAs": "wallet",
  "returnURLPattern": "http://localhost:3000/demo/api/dapp",
