
# Cardano Example Dapp

## **Wallet derivation script**

Derives six spending and six staking keys of the current wallet and builds every kind of address they allow: a reward address, hierarchical deterministic, delegation portfolio and anonymous addresses, native script multisig treasuries and Plutus smart contract addresses. Nothing is submitted on-chain and every address is exported back to dapp for inspection
