
# Cardano Example Dapp

## **Load Wallet Config Demo**

Loads a wallet configuration with five workspaces: default, multi-delegation, hierarchical deterministic, anonymous, and anonymous multi-delegation. Child keys are derived and the addresses each workspace needs are built, then the loaded profile is exported. Workspaces are virtual groups of keys and addresses that give users a specialized wallet experience. See 'Save Wallet Config Demo' to persist one
